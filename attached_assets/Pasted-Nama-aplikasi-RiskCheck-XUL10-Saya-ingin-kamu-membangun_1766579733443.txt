Nama aplikasi: RiskCheck XUL10

Saya ingin kamu membangun web app sederhana berbentuk “Risk Check Tool” berdasarkan tesis PDF yang saya upload.

TUJUAN APLIKASI
- Membantu user mengecek kelayakan & risiko penggunaan strategi Martingale vs Linear Averaging pada transaksi XUL10 (SPA PBK).
- Ini aplikasi edukasi mitigasi risiko. BUKAN aplikasi trading. BUKAN pemberi sinyal entry/exit. BUKAN chatbot tanya jawab bebas.

ATURAN KETAT (GUARDRAILS)
- Jangan pernah memberi rekomendasi transaksi (“buy/sell sekarang”, “entry di harga sekian”, dsb).
- Output harus berupa keputusan risk status: AMAN / BERISIKO / TIDAK LAYAK + alasan singkat bahasa awam.
- Semua logika harus mengikuti isi tesis PDF (parameter target poin 30/40/50, batas layer 5, konsep margin call, tail risk, maximum drawdown, PF/ROM/ER, serta faktor perilaku trader).
- Jika input user tidak lengkap atau tidak masuk akal (misalnya modal 0), tampilkan error yang ramah.

FITUR MINIMUM (MVP)
Buat 2 halaman:
1) / (Input Form)
   Field:
   - Modal awal (USD) -> number
   - Target poin per siklus -> pilihan: 30, 40, 50
   - Strategi -> pilihan: Martingale, Linear Averaging
   - Batas layer maksimal -> pilihan: 3, 4, 5 (default 5)
   - Pengalaman -> pilihan: Pemula (<1 tahun), Berpengalaman (>3 tahun)
   - Kondisi pasar -> pilihan: Sideways, Trending
   Tombol: “Cek Risiko”

2) /result (Hasil)
   Tampilkan:
   - Risk Status (AMAN / BERISIKO / TIDAK LAYAK)
   - Ringkasan alasan (3-6 kalimat bahasa awam)
   - Peringatan utama (bullet)
   - Catatan psikologi trading (overconfidence, loss aversion, risk misperception) dalam bahasa awam (2-4 bullet)
   - Disclaimer: “Edukasi & mitigasi risiko, bukan saran transaksi.”

LOGIKA PENILAIAN (versi awal yang bisa kamu implementasi)
Karena tidak semua angka detail bisa di-hardcode dari PDF secara pasti, buat rule-based scoring yang selaras dengan temuan tesis:
- Martingale + Trending => risiko naik signifikan
- Target 50 => risiko lebih tinggi dibanding 30/40
- Layer 5 => risiko lebih tinggi dibanding 3/4
- Pemula => risiko naik
- Modal kecil + parameter agresif => TIDAK LAYAK
Gunakan sistem skor 0-100:
- 0-39 => AMAN
- 40-69 => BERISIKO
- 70-100 => TIDAK LAYAK
Tampilkan juga “Skor Risiko: XX/100”.
