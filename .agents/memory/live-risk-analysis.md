The user is exploring evolving RiskCheck XUL10 from fixed thesis-based scoring toward real-time pricing with technical and fundamental analysis to inform martingale or averaging scenarios. This is an idea for discussion, not authorization to implement or automate trading.

**How to apply:** Before implementation, discuss the verified source for the exact XUL10 contract, licensed real-time and historical data, fundamental-data scope, risk limits, and analysis-only versus broker execution. Keep automated order placement out of scope unless explicitly agreed.
